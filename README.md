# Map Overlays for Google Maps (Chrome extension)

Finds Google Maps JS API widgets on any website (Zillow, Redfin, apartment sites, `<gmp-map>` embeds…)
and draws overlays on top of them:
- **WMATA Metro**: all six lines in official colors, shared track drawn side by side, every station
  marked; hover a station for its name and lines.
- **WMATA Metrobus** (off by default): every route in its GTFS service-tier color, all stops from a
  chosen zoom level (default 15); click a stop for its routes, click a route to highlight it.

## Use
- `./launch-chrome.sh [url]` starts Chrome for Testing with the `./chrome/` profile, the extension
  loaded, and remote debugging on `:9222` (used by the `chrome-devtools` MCP server in `.mcp.json`).
- Or in any Chrome: `chrome://extensions` → Developer mode → *Load unpacked* → `extension/`.
- Toolbar popup: master on/off; Metro on/off, per-line toggles, stations, station names, opacity;
  Metrobus on/off, routes, stops + minimum stop zoom, opacity.
- `Alt+Shift+M` toggles all overlays.

## How it works
- `extension/src/page/core.js` (page world, `document_start`) traps `window.google.maps.Map` with a Proxy and
  also wraps Map/MVCObject/`google.maps.event`/`setMap` methods, so maps created before the hook are
  caught the next time the page uses them. Overlays (`metro.js`, `bus.js`) register in
  `window.__gmo.overlays` and draw with `canvas-layer.js`, a canvas in the map's overlay pane.
- `extension/src/bridge.js` (isolated world) relays settings (`chrome.storage.sync`) and data.
- `extension/data/wmata.json` is generated by `node tools/build-wmata-data.mjs` from DC Open Data.
- `extension/data/bus.json` is generated by `node tools/build-bus-data.mjs` from WMATA's official
  Metrobus GTFS (public Mobility Database mirror). Re-run it when WMATA publishes a new schedule.
- Each dataset is only loaded into a page when its overlay is on and a map was found.

## Limits
- Only Google Maps JS API maps (not Mapbox/Leaflet, not the `google.com/maps/embed` iframe).
- Hidden on tilted/rotated vector maps.
